# Easy Hand Pose - Fingertip Trail

## What this teaches
- ml5 `handPose` tracking one hand
- Reading landmark points (`indexTip`, `thumbTip`)
- Using pinch distance as a simple interaction switch

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Move your index finger to draw; pinch to change trail color.

## Creative tweak ideas
- Use pinch to clear the whole trail.
- Add a brush size that changes with finger speed.
