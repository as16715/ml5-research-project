# Easy Image Classification - Label Reactor

## What this teaches
- ml5 `imageClassifier` with MobileNet
- Repeated live classification from webcam frames
- Mapping labels to simple visual reactions

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Show different objects to the camera.

## Creative tweak ideas
- Add your own color mapping for labels you like.
- Replace the label tag with your own symbols.
