# Face Mesh - Advanced Astral Drift

## What this teaches
- ml5 `faceMesh` with stylized, full-screen visuals
- Rendering face landmarks with a cinematic look
- Optional debug overlay for keypoint inspection

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Press `F` to toggle the debug panel.

## Creative tweak ideas
- Switch the color theme based on mouth openness.
- Add a subtle starfield background for depth.
