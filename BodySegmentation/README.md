# Easy Body Segmentation - Person Aura

## What this teaches
- ml5 `bodySegmentation` with `SelfieSegmentation`
- Real-time person mask from webcam
- Using mask overlays for quick creative visuals

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Move around and watch your segmented aura change color.

## Creative tweak ideas
- Swap to `BodyPix` and compare mask styles.
- Add keyboard keys to switch aura palettes.
