# Easy Sentiment Analysis - Mood Meter

## What this teaches
- ml5 `sentiment` model with `MovieReviews`
- Predicting sentiment score for free-form text
- Turning model output into a simple visual meter

## Run
1. Open `index.html` in a browser.
2. Type your own sentence.
3. Click Analyze (or press Enter) to update the meter.

## Creative tweak ideas
- Color the page background from red to green based on score.
- Keep a history of the last five scores.
