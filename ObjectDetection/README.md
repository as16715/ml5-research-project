# Easy Object Detection - Biggest Box

## What this teaches
- ml5 `objectDetection` with COCO-SSD
- Running detection continuously on webcam frames
- Highlighting one selected detection (largest object)

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Move objects closer/farther and watch the highlighted box change.

## Creative tweak ideas
- Highlight the smallest object instead.
- Change spotlight color by object label.
