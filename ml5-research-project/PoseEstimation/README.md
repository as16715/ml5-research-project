# Easy Pose Estimation - Joint Radar

## What this teaches
- ml5 `bodyPose` with MoveNet
- Reading named keypoints (`left_wrist`, `right_wrist`)
- Mapping body position to visual size feedback

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Raise and lower your wrists to change circle size.

## Creative tweak ideas
- Use shoulder height instead of wrists.
- Trigger color changes when both wrists go above your head.
