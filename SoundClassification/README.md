# Easy Sound Classification - Sound Color

## What this teaches
- ml5 `soundClassifier` with SpeechCommands18w
- Reliable microphone start flow through explicit button click
- Mapping sound labels to color and pulse size

## Run
1. Open `index.html` in a browser.
2. Press the `Start Microphone` button and allow access.
3. Make sounds and watch label + confidence updates.

## Creative tweak ideas
- Trigger shape changes from specific labels.
- Add a short label history panel.
