# Face Mesh - Easy Starter

## What this teaches
- ml5 `faceMesh` detection with one face
- Turning mouth openness and blinks into visuals
- Handling face keypoints for simple interactions

## Run
1. Open `index.html` in a browser.
2. Allow camera access.
3. Open your mouth and blink to trigger the effects.

## Creative tweak ideas
- Map mouth openness to a color palette switch.
- Add a key to toggle the ripple effect on and off.
