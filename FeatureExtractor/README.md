# Easy Feature Extractor - Two-Class Trainer

## What this teaches
- ml5 `featureExtractor` with MobileNet features
- Capturing webcam samples into class labels
- Training a tiny in-browser classifier from your own examples

## Run
1. Open `index.html` in a browser.
2. Add sample images for class A and class B.
3. Press Train and watch live predictions.

## Creative tweak ideas
- Rename classes to your own gestures or objects.
- Add a third class button.
